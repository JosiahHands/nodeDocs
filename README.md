# nodeDocs

The complete Node.js API documentation as one continuous Markdown file, made for listening from start to finish with Microsoft Edge Read Aloud.

**Main file: [Nodejs_API_Docs.md](Nodejs_API_Docs.md)** (one file, about 5.1 MB, all 68 modules)

- Source: the official Node.js API documentation, https://nodejs.org/docs/latest/api/
- Version: v26.12.1
- Contents: all 68 modules of the official table of contents, in the official order, each starting with its own top-level heading. A short linked contents list sits at the top of the file.
- Text: taken from the Node.js documentation pages and converted to Markdown. Code samples that the website shows in two versions keep both, each with a short label (ES module version or CommonJS version). Links between modules point to the matching heading inside the same file.

## Important: GitHub does not display this file

The file is too large for GitHub to show. Opening it on github.com shows "View raw" and the message "Sorry about that, but we can't show files that are this big right now." The raw link opens the whole file as plain text in Edge:

https://raw.githubusercontent.com/JosiahHands/nodeDocs/main/Nodejs_API_Docs.md

As plain text, the Markdown symbols stay visible (for example "#" before headings and link addresses in parentheses), and Read Aloud may read some of them.

## How to listen in Edge (untested)

These steps are a suggestion and have not been tested yet.

1. Open the raw link above in Microsoft Edge.
2. Click at the point where you want to start, or at the top of the page.
3. Start Read Aloud with Ctrl+Shift+U, or right-click the text and choose the Read aloud option.

## Listening notes

- Code blocks and the History and "Added in" version lines are read aloud too. A lighter version without them can be made on request.
- DTLS: the DTLS page is documented on nodejs.org but is not in the official sidebar table of contents, so it is not included. It can be added on request.
