# nodeDocs

The complete Node.js API documentation as one continuous file, made for listening from start to finish with Microsoft Edge Read Aloud. It comes in two versions of the same single document.

**For listening: [Nodejs_API_Docs.txt](Nodejs_API_Docs.txt)** (plain text, about 3.9 MB). Open it directly here:

https://raw.githubusercontent.com/JosiahHands/nodeDocs/main/Nodejs_API_Docs.txt

**Markdown: [Nodejs_API_Docs.md](Nodejs_API_Docs.md)** (about 5.1 MB, with headings, links and code formatting)

- Source: the official Node.js API documentation, https://nodejs.org/docs/latest/api/
- Version: v26.12.1
- Contents: all 68 modules of the official table of contents, in the official order.

## The plain-text version

The same text as the Markdown file, prepared for listening:

- Link wording is kept and link addresses are removed.
- Heading marks, backticks and other Markdown symbols are removed.
- Each module starts with a line like "Section 12 of 68: File system".
- Tables are read as rows, for example "Node-API version: 10. Supported In: ...".
- Type names are plain words, for example "path (string or Buffer or URL): ...".
- Each code example starts with "Code example:" (or "ES module version:" / "CommonJS version:") and ends with "End of code."

## Important: GitHub does not display these files

Both files are too large for GitHub to show on its normal page, which says "View raw" instead. Use the raw links above. The Markdown file viewed raw shows its symbols and link addresses, which Read Aloud may speak, so the plain-text version is the one meant for listening.

## How to listen in Edge (untested)

These steps are a suggestion and have not been tested yet.

1. Open the plain-text raw link above in Microsoft Edge.
2. Click at the point where you want to start, or at the top of the page.
3. Start Read Aloud with Ctrl+Shift+U, or right-click the text and choose the Read aloud option.

## Listening notes

- Code examples and the History and "Added in" version lines are read aloud too. A lighter version without them can be made on request.
- DTLS: the DTLS page is documented on nodejs.org but is not in the official sidebar table of contents, so it is not included. It can be added on request.
